# docs-tools

## Overview

A set of specialized agents that generate documentation from code, assist with
database schema migrations, and scan for security vulnerabilities.

## Components

- **Agents**
  - `doc-generator` — generate markdown docs from code, comments, and type signatures
  - `migration-assistant` — generate schema migration and rollback scripts
  - `security-scanner` — scan code and dependencies for OWASP top 10 issues

## Usage

```bash
ihub pull docs-tools --install
```
